# Correctness testing

This directory contains test programs and input data used to evaluate the correctness of the algorithm. 
Parser generated by our algorithm is being tested against parser generated by Bison.

## Contents

Each test folder includes:

- Input grammars for:
  - **Bison**
  - **Our algorithm**
- Testing input files
- A parser generated by our algorithm
- A `Makefile` for building and running the tests

## Requirements

In addition to the main project requirements, this testing module also requires:

- **GNU Bison** — used to generate the reference parser from the `bison_parser.y` grammar file.

## Installing Bison

### Ubuntu / Debian
```bash
sudo apt install bison
```

### Fedora
```bash
sudo dnf install bison
```

## Building the Tests

To compile the test program, run:

```bash
make
```

## Running the Tests

After compilation, execute the test with:

```bash
./test
```
